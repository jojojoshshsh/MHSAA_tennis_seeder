Michigan High School Tennis Rankings

How the rankings work

← Back to Rankings About

Overview

These rankings aim to estimate the seed a player would receive at the MHSAA state tournament based on the full body of match results available on TennisReporting.com. The system is built around the idea that who you beat matters more than how many you beat — a win over a player who in turn beat many others carries more weight than a win over someone with no competitive record.

Rankings are computed separately for Singles and Doubles, for Boys and Girls, across Flights 1–4. Each gender + match type + flight is ranked as one cross-division pool, then published two ways: split into the four MHSAA divisions, and as a single cross-division General Ranking for that flight.

Two ideas do the work. A graph-based seed ordering (who beat whom, directly or through a chain of wins) decides the ranked order. A capped game-margin Power Rating breaks the ties the graph can't settle and also drives the strength-of-schedule stats, the matchup simulator and the state tournament predictions.

Important: the ranked order comes from the pipeline described in Steps 1–4 below. The Power Rating only decides a pair of neighbors when head-to-head, common opponents and transitive wins all fail to separate them.

The Ranking Pipeline

Each gender + match type + flight combination is ranked as one cross-division group, then split into divisions afterward. The pipeline runs four steps, plus a fifth that builds the General Ranking.

1 Cycle Removal

Match results are loaded into a directed win graph: an arrow points from winner to loser. Before any ranking can happen, every cycle in this graph must be broken — a cycle means player A beat B, B beat C, and C beat A, which makes a strict ordering impossible.

The engine finds every cycle (of any length, including simple head-to-head upsets) and removes the oldest match on each cycle. This preserves the most recent competitive evidence and discards results that have been superseded by more recent play. If several matches on the cycle share the oldest date, the one with the narrowest margin of victory is removed. This repeats until the graph is fully acyclic (a DAG).

Some matches never enter the ranking graph at all: matches that ended after only one set, matches with a score of exactly "2-0 2-0" (a short-set placeholder), and matches where either side's name contains "default" (a walkover recorded against a stand-in name). They still count toward win/loss records, but not toward ordering.

2 Transitive Closure & Initial Order

On the acyclic graph, each player's transitive win set is computed: every player they can reach by following any chain of win-edges. If you beat A and A beat B, your transitive win set includes both A and B.

Players are sorted by the size of this set, descending. Beating players who have themselves beaten many others produces a larger reachable set and a higher seed. When two players' reachable sets are the same size (because they're incomparable in the graph), ties fall back in this order:

  1. More recent match activity (each win counts 1 ÷ days ago, each loss counts −0.5 ÷ days ago)
  2. Better average score margin across all matches
  3. Higher TrueSkill rating (μ)
  4. Alphabetical by name — only so the same input always produces the same order

3 Division Split

The cross-division order from Step 2 is partitioned into the four MHSAA divisions, preserving the relative order within each division. No new comparisons are made at this stage — the split is a pure filter on an already-settled order.

4 Adjacent Fix-Up Pass

Within each division, the engine walks adjacent pairs top-to-bottom and checks whether the lower-ranked player should actually outrank the one above them. Four criteria are checked in strict priority order, and the first one that separates the pair decides it:

PriorityCriterionHow it's decided
1 Head-to-head Most recent match between the two players
2 Common opponents — wins Who won more matches against shared opponents
2b Common opponents — margin If tied on wins: cumulative game margin against shared opponents. A match (10-point) tiebreak counts as an ordinary 7-6 set so it can't skew the total.
3 Transitive dominance Does one player's transitive win set contain the other?
4 Power Rating Higher Power Rating, as a last resort

If the lower-ranked player wins any of these checks, the two are swapped. The pass repeats from the top until a full pass produces zero swaps (the order is fully stable). The "Why ranked below" column shown on the site reflects whichever criterion decided each adjacent pair in the final stable order.

5 General Ranking (all divisions)

The same Step 2 order is also run through the Step 4 fix-up pass against the entire cross-division roster for the flight, with no division split. The result is one flight-wide ranking (for example, Boys Singles Flight 2 with every division combined), published under General Rankings alongside the per-division lists. It uses exactly the same four criteria.

Power Rating

The Power Rating is a game-margin rating fit to every ranking-eligible match in a pool (gender + match type + flight). Its meaning is deliberately concrete: the gap between two players' ratings is how many games the better player is expected to win by, capped at 12.

expected margin of A over B = min( rating_A − rating_B , 12 )
Rating gapTypical result
126-0 6-0
~6Something like 6-3 6-3 or 6-2 6-4
27-6 7-6
1A three-set toss-up (e.g. 6-7 7-6 10-2)
0Coin flip

Each match contributes its game margin (a match tiebreak counts as an ordinary 7-6, so 6-7 7-6 10-2 is worth +1 game). A win is always worth at least 1 game and at most 12. A light ridge penalty pulls players with very few matches toward the pool average so a handful of results can't produce an extreme rating; its strength was tuned by fitting on the earlier part of each flight's season and checking predictions on the most recent matches.

Note: rating gaps only mean something within a pool. Boys singles Flight 1 and Girls doubles Flight 3 are fit separately, so don't subtract ratings across pools.

TrueSkill

The engine also fits a TrueSkill rating (Herbrich et al., 2007) to each pool. It is margin-aware — a 6-0 6-0 win moves ratings more than a 7-6 7-6 win, and a match tiebreak is treated as a bare win — and it tracks a volatility signal inspired by Glicko-2. TrueSkill's μ is used in one place in the ranking: as the third tiebreaker when the initial order in Step 2 is otherwise tied. It is also shown in the tables as ts_mu. It no longer breaks ties in the fix-up pass (the Power Rating does) and no longer feeds any composite score.

Won After Set 1 Loss

A simple comeback-rate stat. For every match a player has played, the engine checks who won the first set. If the player lost set 1 but still went on to win the match overall, that counts as a comeback win. The column shows wins / opportunities along with the percentage — for example, 3/5 (60%) means the player lost the first set five times and came back to win the match three of those times. The cell is left blank for players who have never lost a first set.

This stat is drawn from every match on record for that player, including matches against opponents in other divisions and matches that were excluded from the ranking graph — the same broad match history used for the win/loss record. It does not feed into the ranking.

Record vs Weaker / Mid / Top Opponents

This stat groups opponents by their Power Rating, so a player's schedule is measured by how strong their opponents are expected to be, not just how often those opponents happened to win. It uses the same rating as the matchup simulator and state predictions.

The two dividing lines (the 50th and 75th percentile of Power Rating) are calculated once for each gender + match type + flight, using everyone rated in that cross-division pool, so every division is judged against the same bar. A player's record is then measured against those thresholds:

ColumnOpponent ratingWhat it means
vs Weaker Opp Below the 50th percentile Record against opponents in the bottom half of the pool
vs Mid Opp 50th–75th percentile Record against opponents in the upper-middle of the pool
vs Top Opp 75th percentile and above Record against the top quarter of the pool — the toughest opponents

A player's record counts every opponent they've played, including opponents from other divisions. Each column is formatted as wins-losses (win %), e.g. 5-2 (71%), and is left blank if the player has no recorded matches in that bucket. Like the Power Rating itself, these buckets shift as more matches are played, so treat them as a current snapshot rather than a fixed classification.

Team Rankings

Team scores blend two independent 0–100 scores into a single combined score, weighted 50/50. Both are built from the same eight lineup slots — Singles flights 1–4 and Doubles flights 1–4 — using only one entry per school per slot: the highest-ranked player or pair from that school in that flight.

combined_score = (0.5 × total_points) + (0.5 × depth_score)

Depth Score

The depth score rewards schools that field strong entrants across the whole lineup rather than a couple of standout flights. For a league of N schools — every school fielding at least one ranked entrant anywhere in this gender/division group — each flight rank is converted to a 0–100 scale:

flight_score = (N − rank + 1) / N × 100 depth_score = average(flight_score across all 8 flights)

On this scale, 1st place in a flight scores 100 and last place (rank N) scores just above 0. If a school has no entrant in a given flight, that flight isn't left out of the average — it's scored as if the school finished in rank N + 1, worse than every other school in the league. This keeps a school that only fielded a handful of flights from posting an inflated depth score.

Why two scores? Legacy points reward marquee finishes — a flight winner is worth more than a strong-but-not-top finisher — while the depth score rewards fielding a genuinely deep lineup across all eight slots, including flights that don't place highly. Blending them 50/50 keeps either effect from dominating the team table on its own.

Team Strength of Schedule

team_sos and team_local_sos average the sos and local_sos of the best entrant in each slot the school actually filled. Empty slots are skipped rather than penalized, since strength of schedule only describes matches that were actually played. These columns are informational and don't affect the team rank.

Teams are ranked by combined score (ties are broken first by total_points, then by depth_score). The page shows the top 10 schools per gender and division, with a Show All Teams button to expand the full list. The Slots column counts the slots that earned points, and the last column lists the finishing position of that school's best entrant in every flight it filled, as a quick summary of where its points came from — this is a recap of that team's own results, not a comparison against the team ranked directly above it.

Note: team rankings are experimental. Because individual rankings require a minimum match count (default: 5), some schools may be missing players in certain slots even if they competed in that flight — and under the current scoring, a missing slot counts against both total_points and depth_score.

Predictions & Tools

The State Tournament Prediction page and the Simulate Matchup tool are both driven by the Power Rating. The rating gap is turned into a point-by-point win probability, then into exact game, set and match-score odds for a best-of-three match. Because players have good and bad days and ratings carry estimation error, the gap is treated as a range rather than a fixed number (a 3-game day-to-day spread plus each rating's own uncertainty), which keeps upsets possible. A small blend (5%) of the historical tendency for the higher seed to win is mixed in, and the weights were chosen by testing on held-out matches. The state projection plays out real 32-player single-elimination brackets (1 vs 32, 16 vs 17, and so on).

Simulate Matchup compares two schools flight by flight. When both schools are in the same division it uses that division's ranking; otherwise it falls back to each school's General Ranking entry so both ranks are on the same scale. Team Compare scores a hand-picked set of teams using either descending points per flight or a per-match bracket format.

Eligibility & Filtering

Several filters shape who is ranked and which matches count:

  • Per-school deduplication: if a school has more than one player (or doubles pair) in the same flight, only one is kept. Among those with at least 5 matches, the one with the most recent match date is kept (an exact date tie goes to whoever has played more). If nobody at the school has 5 matches, the choice is made by recency among all of them. The others' matches are removed from the ranking entirely to avoid contaminating head-to-head and common-opponent data.
  • Minimum matches: a player must have at least 5 recorded matches in a given gender + match type + flight group to be shown in the published rankings. This is counted from all matches including excluded scores, so a player isn't dropped just because some of their results were single-set or defaults. Players below the minimum are still part of the win graph and the rating fits; they simply don't appear in the tables, and don't count toward team scores.
  • Flights: only Flights 1–4 are ranked.

The following matches are excluded from all ranking calculations (but still counted in win/loss records):

  • Matches that ended after only one set (e.g. a retirement mid-match)
  • Matches with a score of exactly "2-0 2-0" (a short-set placeholder used for walkovers)
  • Matches where either side's name contains "default" (a walkover recorded against a placeholder name)

To check how well the pipeline actually predicts real seeding outcomes, the 2025 rankings were compared against the official MHSAA state tournament seed lists for that season. Only the official #1–#6 seeds in each bracket were used for this comparison because not all flights are seeded more than 6.

Data & Limitations

Match data is crawled automatically from TennisReporting.com, the platform used by most Michigan high school tennis programs to report results. Rankings are rebuilt and republished daily at 4am EDT.

Known limitations:

  • The minimum match requirement means players early in the season or with few recorded matches may not appear.
  • Division assignments come from correct_divisions.csv first, then the division label in the match data, then TennisReporting school metadata. Schools with unusual or missing labels are normalised where possible, and some may land in Division 4 when they shouldn't. Corrections can be submitted via correct_divisions.csv in the GitHub repository.
  • Doubles pairs are treated as single entities, and only one pair per school is ranked in each flight (see per-school deduplication above).
  • Regular season and tournament bracket matches are both included. Where deduplication is possible it is applied, but some double-reporting may remain.
  • Rankings cover a single season only — no carry-over from prior years.
  • Because the ranking order is determined by graph structure and pairwise comparisons rather than a single score, adjacent players near the boundary of any seed bracket may legitimately swap from day to day as new match data arrives.
